Quick Reference

Unit Description Use Case
px Pixels - absolute unit Borders, shadows, fixed elements
em Relative to parent element font size Component-scoped sizing
rem Relative to root element font size Global sizing, accessibility
% Percentage of parent Fluid layouts, widths
vw 1% of viewport width Responsive typography, full-width
vh 1% of viewport height Full-height sections, heroes

Conversion Formulas

px to rem: px ÷ root-font-size = rem
px to em: px ÷ parent-font-size = em
px to vw: (px ÷ viewport-width) × 100 = vw
px to vh: (px ÷ viewport-height) × 100 = vh
