About UUID v4

UUID (Universally Unique Identifier) version 4 is a 128-bit identifier generated using random numbers. The format is xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx, where x is any hexadecimal digit and y is 8, 9, A, or B. UUID v4 has approximately 5.3 x 10^36 possible values, making collisions virtually impossible.
