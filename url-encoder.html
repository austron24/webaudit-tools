About URL Encoding

URL encoding (percent-encoding) converts special characters into a format that can be safely transmitted in URLs. Characters like spaces, slashes, and query string delimiters need to be encoded when used as data rather than URL structure. The standard encoding uses a percent sign followed by two hexadecimal digits representing the character's ASCII value.
