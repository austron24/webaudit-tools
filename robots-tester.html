Robots.txt Syntax Reference

User-agent: *

Applies rules to all bots. Use specific names like "Googlebot" for targeted rules.

Disallow: /path/

Blocks access to specified path. Leave empty to allow all.

Allow: /path/

Explicitly allows access. Useful for allowing subdirectories of blocked paths.

Sitemap: URL

Points to your XML sitemap. Can include multiple sitemaps.

* (wildcard)

Matches any sequence of characters. Example: Disallow: /*.pdf

$ (end anchor)

Matches end of URL. Example: Disallow: /*.pdf$ blocks .pdf files only.
